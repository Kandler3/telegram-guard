# Проверки

Перед первой публикацией полный набор тестов прошёл на Windows и Python 3.12:

```text
271 passed in 31.45s
```

Команда воспроизведения:

```powershell
python -m pip install ".[test]"
python -m pytest -q
```

Тесты используют временные каталоги, синтетические сообщения и локальные серверы.
Некоторые проверки Windows/Node требуют соответствующей платформы и установленного
bundled runtime Codex. Интеграционные скрипты `tests/probe_*.mjs` запускаются отдельно;
их успешное выполнение не следует из одного `pytest`.

Покрываются разграничение чтения/записи, авторизация действий, защита локальных
путей, квитанции и запрет повторов неопределённой отправки, редактор доступов,
стриминг, подписки, native stdio bridge, автообнаружение runtime, скачивание
нескольких файлов и сериализация опросов Telethon.

Проверки на mock-сервере не заменяют проверку реального Desktop после обновления.
Ни тесты, ни файловый профиль не являются изоляцией от произвольного процесса
с полными правами той же учётной записи ОС.

Персональные результаты реальных проверок, сообщения, ID настоящих чатов,
сессии, ключи и резервные копии установки в репозиторий не включаются.
